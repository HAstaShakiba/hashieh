لینوکس

برای میزکار GNOME ساخته شده (X11 و Wayland). میانبر: Super Ctrl N. به پایتون ۳٫۸ به بالا و GTK 3 نیاز دارد که اوبونتو از قبل دارد.

بسته‌ی اوبونتو / دبیان

فایل .deb را از آخرین نسخه دانلود کنید و بعد:

sudo apt install ./hashieh_*_all.deb

در اولین اجرا «اجرا هنگام ورود» روشن می‌شود و اگر Super Ctrl N آزاد باشد تنظیم می‌شود. هر دو را از ⚙ می‌توانید عوض کنید.

نصب از کد منبع

در ~/.local نصب می‌شود، با همان تنظیمات اولین اجرا:

git clone https://github.com/HAstaShakiba/hashieh.git
cd hashieh
./install.sh

از SideNotes می‌آیید؟

حاشیه داده‌های SideNotes را می‌خواند؛ پس یادداشت‌ها، رنگ‌ها، چک‌لیست‌ها و تصویرهایتان با شما می‌آیند.

  1. روی مک، SideNotes را ببندید و فایل SideNotes.sqlite را (همراه فایل‌های -wal و -shm) یا یک فایل .snbackup از تنظیمات Backups کپی کنید.
  2. روی سیستم جدید دستور hashieh import /path/to/SideNotes.sqlite را اجرا کنید، یا از منوی ⋯ ▸ Import SideNotes data استفاده کنید.
  3. اختیاری: با hashieh themes install /path/to/SideNotes.app تم‌هایتان را هم بیاورید.

جایگزین رایگان SideNotes برای ویندوز و لینوکس

SideNotes یک نوار یادداشت محبوب برای مک است. حاشیه همین ایده را به ویندوز و لینوکس می‌آورد و روی مک هم اجرا می‌شود: پنلی که از لبه‌ی صفحه باز می‌شود، با پوشه، یادداشت رنگی، Markdown، چک‌لیست و تصویر. رایگان و متن‌باز است؛ بدون حساب کاربری و بدون اشتراک.

همان روش کار

پوشه‌های یادداشت در لبه‌ی صفحه، یک میانبر سراسری برای باز و بسته کردن، و ذخیره‌ی خودکار هنگام تایپ.

یادداشت‌هایتان همراهتان

داده‌ها و تم‌های SideNotes را وارد کنید و هر وقت خواستید از همه‌چیز خروجی JSON بگیرید.

همیشه رایگان

با مجوز MIT و کد منبع در GitHub. بدون حساب کاربری و بدون ردیابی؛ یادداشت‌ها روی کامپیوتر خودتان می‌مانند.

پرسش‌های رایج

آیا SideNotes برای ویندوز یا لینوکس وجود دارد؟

خود SideNotes فقط برای مک ساخته شده است. حاشیه یک پنل یادداشت رایگان و متن‌باز با همین ایده برای ویندوز، لینوکس و مک است: یادداشت‌ها در پوشه‌ها کنار صفحه‌ی نمایش، با یک کلید میانبر.

حاشیه رایگان است؟

بله. حاشیه کاملاً رایگان و متن‌باز (با مجوز MIT) است؛ بدون نسخه‌ی پولی، حساب کاربری یا تبلیغ.

می‌توانم یادداشت‌هایم را از SideNotes منتقل کنم؟

بله. حاشیه داده‌های SideNotes (فایل SideNotes.sqlite، data.json یا ‎.snbackup) را با پوشه‌ها، رنگ یادداشت‌ها، چک‌لیست‌ها و تصویرها وارد می‌کند و تم‌های ‎.sntheme را هم پشتیبانی می‌کند.

پنل یادداشت را چطور باز کنم؟

در ویندوز Ctrl+Alt+N، در مک Cmd+Ctrl+N و در لینوکس Super+Ctrl+N را بزنید، یا روی دستگیره‌ی کوچک کنار صفحه کلیک کنید. کلید میانبر را از تنظیمات می‌توانید عوض کنید.

حاشیه روی چه سیستم‌عامل‌هایی کار می‌کند؟

ویندوز ۱۰ و ۱۱ (۶۴ بیتی)، مک ۱۱ به بعد با پردازنده‌ی Apple Silicon، و لینوکس با میزکار GNOME؛ برای اوبونتو و دبیان بسته‌ی ‎.deb هم دارد.

با iCloud همگام‌سازی می‌شود؟

نه. یادداشت‌ها به‌صورت محلی در یک فایل SQLite روی کامپیوتر خودتان ذخیره می‌شوند. اگر بخواهید، می‌توانید آن‌ها را از راه Google Drive خودتان بین کامپیوترهایتان همگام کنید. از همه‌چیز هم می‌توانید خروجی JSON بگیرید و یادداشت‌های مک را با وارد کردن پایگاه داده‌ی SideNotes منتقل کنید.

حاشیه یک پروژه‌ی مستقل و غیررسمی است. SideNotes علامت تجاری Apptorium است و حاشیه هیچ وابستگی یا تأییدی از Apptorium ندارد. مجوز MIT · حریم خصوصی · کد منبع در GitHub
