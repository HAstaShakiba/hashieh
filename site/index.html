Hashiehحاشیه

A notes panel that lives on the edge of your screen. Jot things down, tick off tasks and keep snippets one shortcut away. You can bring your notes over from SideNotes on the Mac.

Everything a side note needs

Notes appear rendered, the way you read them. Click a note when you want to edit its text.

▏

Docked to the edge

A transparent panel on the left or right edge, above other windows. A small handle brings it back when it's hidden.

◯

Tasks you can tick

Write [ ] and it becomes a circle you can click. Done items stay in place with a check mark.

✱

Light Markdown

Headings, bold, italic, strike, highlight, code, quotes and lists, without leaving plain text.

●

Colors & folders

Six note colors, pinned notes and folders, plus search across everything you've written.

▣

Pictures & files

Paste or drop an image to attach it. Drop a file to keep a link to it in the note.

◐

Themes

A built-in light and dark theme. You can also install the .sntheme themes from your copy of SideNotes.

Install

Get the file for your system from the latest release. On first start Hashieh turns on Start at login and binds a show/hide shortcut if that key is free.

Windows 10 / 11

Run Hashieh-…-windows-x64-setup.exe, which installs per user without admin rights. Shortcut: Ctrl Alt N.

The build isn't signed yet: in SmartScreen click More info ▸ Run anyway.

macOS 11+ (Apple Silicon)

Open Hashieh-…-macos-arm64.dmg and drag Hashieh to Applications. Shortcut: ⌘ Ctrl N.

Not notarized yet: allow it in System Settings ▸ Privacy & Security ▸ Open Anyway.

Linux

Built for GNOME (X11 and Wayland). Shortcut: Super Ctrl N. Needs Python 3.8+ and GTK 3, which Ubuntu already has.

Ubuntu / Debian package

Download the .deb from the latest release, then:

sudo apt install ./hashieh_*_all.deb

On first start it turns on Start at login and binds Super Ctrl N if that key is free. Change either one in ⚙.

From source

Installs into ~/.local, with the same first-start setup:

git clone https://github.com/HAstaShakiba/hashieh.git
cd hashieh
./install.sh

Keyboard first

You can change every shortcut in ⚙ ▸ Keyboard shortcuts. Hashieh tells you if a key is already taken.

Super Ctrl NShow or hide the panel from anywhere
Ctrl NNew note (or folder)
Ctrl FSearch all notes
EscStop editing, go back, hide
Ctrl = / Ctrl -Bigger / smaller text

Coming from SideNotes?

Hashieh reads SideNotes data, so your notes, colors, tasks and pictures come with you.

  1. On your Mac, quit SideNotes and copy SideNotes.sqlite (with its -wal and -shm files), or a .snbackup from its Backups settings.
  2. On Linux, run hashieh import /path/to/SideNotes.sqlite, or use ⋯ ▸ Import SideNotes data.
  3. Optional: hashieh themes install /path/to/SideNotes.app to use your themes.
