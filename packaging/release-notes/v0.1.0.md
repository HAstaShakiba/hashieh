First release of **Hashieh** (حاشیه), a notes panel that lives on the edge of your Linux screen and can import your notes and themes from SideNotes for macOS.

![Hashieh](https://raw.githubusercontent.com/HAstaShakiba/hashieh/main/docs/screenshot.png)

### Highlights
- Docked, transparent panel with floating note cards and a small handle on the screen edge
- Notes are shown rendered: tasks become circles you can tick, `#rrggbb` colors become dots, and pictures appear inline. Click a note to edit it.
- Folders, six note colors, pinning, search, and pictures and file links by paste or drag and drop
- Import from SideNotes (`SideNotes.sqlite`, `data.json`, `.snbackup`) and export to JSON
- Loads SideNotes `.sntheme` themes in light and dark
- A global show/hide shortcut and in-app shortcuts, all configurable in ⚙ ▸ Keyboard shortcuts…
- Start at login

### Install
**Debian / Ubuntu:**
```bash
sudo apt install ./hashieh_0.1.0_all.deb
```
**From source:** unpack `hashieh-0.1.0.tar.gz`, then run `./install.sh --autostart --shortcut '<Super><Control>n'`.

You need Python 3.8+ and GTK 3 (`python3-gi`, `python3-gi-cairo`, `gir1.2-gtk-3.0`). The panel is built for GNOME; on Wayland it runs through XWayland so it can stay docked.

Verify the downloads with `sha256sum -c SHA256SUMS`.
