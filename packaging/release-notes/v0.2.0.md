**Hashieh now runs on Windows and macOS too.**

### New
- **Windows 10/11 (x64):** an installer (per user, no admin rights needed) and a portable `.zip`. The show/hide shortcut is **Ctrl+Alt+N**.
- **macOS 11+ (Apple Silicon):** a `.dmg`. The show/hide shortcut is **Cmd+Ctrl+N**. There's no Dock icon; Hashieh lives on the screen edge like SideNotes.
- On every system, the first start turns on *Start at login* and binds the shortcut if the key is free. You can change both in ⚙ ▸ Keyboard shortcuts.
- In-app shortcuts use Cmd on macOS and Ctrl elsewhere.
- Starting Hashieh again while it's running (from the Start menu or the Dock, for example) brings up the running panel instead of opening a second copy.

### Known limitations
- The Windows and macOS builds aren't code-signed yet. On Windows click *More info ▸ Run anyway*. On macOS use *System Settings ▸ Privacy & Security ▸ Open Anyway*.
- The builds bundle GTK 3, so they don't look fully native, and they're about 30 MB.
- There's no Intel Mac build yet.
- The macOS build was tested on CI runners, not on a real Mac yet. Please [report problems](https://github.com/HAstaShakiba/hashieh/issues).

### Install
| System | File |
|---|---|
| Ubuntu / Debian | `hashieh_0.2.0_all.deb`, then `sudo apt install ./hashieh_0.2.0_all.deb` |
| Windows | `Hashieh-0.2.0-windows-x64-setup.exe` (or `Hashieh-0.2.0-windows-x64.zip`) |
| macOS | `Hashieh-0.2.0-macos-arm64.dmg` |

Verify the downloads with `sha256sum -c SHA256SUMS`.
