Maintenance release. The app is the same as 0.1.0; this release is the first one built and published automatically.

### What's new
- **Website:** https://hastashakiba.github.io/hashieh/, with features, install steps, shortcuts and SideNotes migration notes. Its download button always points to the latest `.deb`.
- **Continuous integration:** every push and pull request runs the tests and builds and checks the packages on Ubuntu 22.04 and 24.04.
- **Automated releases:** pushing a `vX.Y.Z` tag runs the tests, builds the packages and publishes the release.

### Install
```bash
sudo apt install ./hashieh_0.1.1_all.deb
```
Or unpack `hashieh-0.1.1.tar.gz` and run `./install.sh --autostart --shortcut '<Super><Control>n'`.

Verify the downloads with `sha256sum -c SHA256SUMS`.
