### New
- **Works out of the box:** the first time Hashieh starts, it turns on *Start at login* and binds **Super+Ctrl+N** to show and hide the panel. The shortcut is only bound if no other program on your desktop uses that key. This happens once, so if you change or turn off either one in ⚙, Hashieh won't turn it back on.
- `install.sh` no longer needs `--autostart` or `--shortcut` to get these defaults.

### Install / upgrade
```bash
sudo apt install ./hashieh_0.1.3_all.deb
```
If you already use Hashieh, your current shortcut and autostart setting are kept.

Verify the downloads with `sha256sum -c SHA256SUMS`.
