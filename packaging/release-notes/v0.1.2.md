Bug fix release.

### Fixed
- The `.deb` launcher failed with `ImportError: cannot import name '_gi'` on systems where `/usr/bin/python3` has been switched (for example with `update-alternatives`) to a Python version that `python3-gi` isn't built for. The launcher now picks an installed Python that has GTK 3, just like the source launcher already did.

### Install / upgrade
```bash
sudo apt install ./hashieh_0.1.2_all.deb
```

Verify the downloads with `sha256sum -c SHA256SUMS`.
